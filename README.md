# Crosshair X Linux Patcher
 a patcher to make crosshair x work on linux

## Instructions

```
git clone https://github.com/Blazzy12/Crosshair-X-Linux-Patcher.git
cd Crosshair-X-Linux-Patcher/
```

Install
```
./crosshairx-linux-installer.sh
```
Uninstall
```
./crosshairx-linux-installer.sh --uninstall
```
